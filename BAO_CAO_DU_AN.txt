Hệ thống tag nội bộ (cột GhiChu của DAT_PHONG):
  [PT_COC:method]       — Phương thức đặt cọc (tien_mat/chuyen_khoan/qr)
  [PT_FULL:method]      — Khách thanh toán 100% khi đặt phòng
  [BALANCE_PT:method]   — Thanh toán phần còn lại qua pay-balance.php
  [VAT:amount]          — Tiền VAT đã tính (1%)
  [KM:code note]        — Khuyến mãi đã áp dụng
  [HUY_KH:timestamp]    — Khách tự hủy đặt phòng
  [HOAN_TIEN:amount]    — Số tiền cần hoàn (theo chính sách)
  [HOAN_TK:stk|nh|ten] — Thông tin ngân hàng nhận hoàn tiền
  [LY_DO:text]          — Lý do hủy do khách cung cấp
  [DA_HOAN:timestamp]   — Admin đánh dấu đã hoàn tiền xong

V. HỆ THỐNG BẢO MẬT
────────────────────────────────────────────────────────────────

5.1. Xác thực & Phân quyền
  • Mật khẩu hash bằng password_hash() (Bcrypt, PHP built-in)
  • Session name riêng: EASYHOME_SID (tránh conflict với phpMyAdmin)
  • Cookie SameSite=Lax (chống CSRF cơ bản)
  • Kiểm tra session đầu mỗi trang protected (redirect nếu chưa đăng nhập)
  • Phân quyền theo staff_role (admin/nhanvien) và kh_role (khachhang)

5.2. Bảo vệ CSRF
  • csrfToken(): sinh token 64 ký tự hex ngẫu nhiên, lưu vào session
  • csrfField(): nhúng hidden input vào mọi form POST
  • csrfVerify(): kiểm tra hash_equals(), die(403) nếu sai
  → Áp dụng cho TẤT CẢ form POST trong toàn hệ thống

5.3. Bảo vệ Brute-force
  • Theo dõi số lần sai theo IP, lưu JSON tại server
  • Sau 5 lần sai: khóa IP 15 phút
  • Hiển thị dots indicator (●●●●● / ○) + countdown JS
  • Tự động mở khóa sau 15 phút

5.4. SQL Injection
  • 100% truy vấn dùng PDO Prepared Statements (không nối chuỗi SQL)
  • PDO::ATTR_EMULATE_PREPARES = false (dùng true prepared statements)

5.5. XSS Prevention
  • htmlspecialchars() cho mọi output dữ liệu từ DB ra HTML
  • cleanNote(): hàm lọc bỏ tag nội bộ khỏi GhiChu trước khi hiển thị cho KH

5.6. Mã hóa CCCD (AES-256-CBC)
  • encryptCCCD(): mã hóa trước khi lưu → "ENC:<base64(iv+cipher)>"
  • decryptCCCD(): giải mã khi cần hiển thị đầy đủ (form chỉnh sửa)
  • maskCCCD(): che ****xxxx (chỉ lộ 4 số cuối) khi xem
  • Key 64 ký tự hex, lưu trong config/mail-secret.php (gitignored)
  • Backward-compatible: dữ liệu plaintext cũ không bị lỗi

5.7. Bảo vệ file (.htaccess)
  • ErrorDocument 404 → 404.php (route toàn bộ lỗi 404)
  • Options -Indexes (cấm duyệt thư mục)
  • FilesMatch .md/.sql → Require all denied (không xem CLAUDE.md, hotel_db.sql)
  • config/.htaccess: Require all denied (cấm HTTP vào thư mục config)

5.8. Email bảo mật
  • SMTP Gmail qua STARTTLS (port 587)
  • App Password (không dùng mật khẩu Gmail trực tiếp)
  • ssl_verify_peer = false (fix XAMPP local OpenSSL)
  • Credentials lưu config/mail-secret.php (gitignored, không commit)
